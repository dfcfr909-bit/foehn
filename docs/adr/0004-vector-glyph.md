# ADR-0004: 天気記号を絵文字でなく自前ベクターで描く

- ステータス: 採用
- 日付: 2026-08-07（記録日。実装は v4.40.0）

## 背景

チャート上部に2時間ごと（v4.37.0以前は6時間ごと）の天気アイコンを置く。
当初は `weatherEmoji()` が返す**絵文字**を、白い丸の座布団の上に載せて描いていた。

実機で2つの問題が出た。

1. **色が淡くて、小さいと判別しづらい。** 端末のフォント任せなので濃さを制御できない
2. **字形ごとに重心が違い、丸の中心に合わない。** ☀と🌧では見た目の中心が別の位置にあり、
   一律のオフセットでは揃わない

## 決定

`drawWeatherGlyph()` を用意し、**太陽・月・雲・雨・雪・雷・霧を原色寄りのべた塗りで自前描画する**。
天気区分は `weatherEmoji()` と同じものを使う。
月は絵記号ではなく**実際の満ち欠け**を描く（`moonPhase()` + `wxMoon()`、v4.41.0）。

座布団の半径 `icoR` は `pxPerHourVal - 0.6`（＝2時間間隔で隣の丸と接しないギリギリ）。

## 理由 / 検討した代案

- **なぜ自前ベクターか**
  - 色・太さ・重心をこちらで決められる。小さくても判別できる濃さに固定できる
  - 端末やOSのフォント差で見た目が変わらない
  - 丸の中心＝描画の中心なので、座布団との位置合わせが構造的にズレない

- **却下: 絵文字のまま、サイズを上げる／濃く見えるよう座布団を工夫する**
  - 上記1・2の原因はどちらもフォント側にあり、こちら側の調整では消えない。
    重心のズレは字形ごとに違うので、当て込みの補正は天気区分の数だけ壊れる

- **却下: 天気アイコンの画像素材（PNG/SVGスプライト）を持ち込む**
  - 単一HTML構成（ADR-0001）にバイナリ素材を増やすことになる。
    描くのは7種類の単純な図形なので、コードで持つ方が軽い

- **却下: `destination-out` で丸を抜く描き方**
  - **一度やって失敗した。下の白い座布団ごと消える。**
    `destination-out` は同じcanvas上の既に描いたものを対象に抜くため、
    記号の抜きのつもりが座布団まで抜ける。**この方式に戻さないこと**

- 選択情報のポップアップだけは**絵文字のまま**にしてある。
  こちらは大きく表示されるので、上記の判別性の問題が出ない

## 影響

- **`destination-out` を使わない。** 抜きたい形があるなら、
  背景色でべた塗りするか、パスの組み立て（`evenodd` 等）で解決する
- 日付ラベルとアイコンが重ならないよう、気温パネルの上部余白は `SKY_TOP_PAD`(46px)。
  ここを詰めると重なる
- 天気区分を増やすときは `weatherEmoji()` と `drawWeatherGlyph()` の**両方**を直す
- 月の満ち欠けは平均朔望月からの近似で、誤差は概ね±0.5日。
  「形を見て満月に近いと分かれば十分」という用途向けなので、
  **潮汐や暦には使わないこと**
