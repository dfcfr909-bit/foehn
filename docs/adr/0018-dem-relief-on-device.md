# ADR-0018: 地形の図（CS立体図風）を、地理院の標高タイルから端末で描く

- ステータス: 採用
- 日付: 2026-10-12

## 背景

登山中に「欲しい地図が現地で見られないならなんの意味もない」（利用者）。CS立体図の配信は栃木県だけ（#112）で、
全国版は利用条件の問い合わせ中。地理院の標高タイルは DEM5A（5m・航空レーザー・z15 まで）と DEM10B（10m・全国・z14 まで）があり、
百名山28峰の試しで DEM5A は27峰の山頂タイルにあった（羅臼岳だけ無し・2026-10-12）。
試作（`experiments/relief/viewer.html`）では DEM5A z15 の CS が1枚約15ms（ヘッドレス）。CIマップ（#202）で Worker で描く仕組みは本体にある。

## 決定

- CIマップの仕組み（取得・Worker・メインへの退避）を、源と計算の種類を選べる形に一般化し、「CS立体図風（全国）」を足す
- 源は **DEM5A を先に試し、9枚（中心＋周り8）のうち1枚でも配信なし（403・404）なら9枚とも DEM10B**
- **DEM10B に落とすのは配信なしのときだけ。** 通信の失敗（圏外で sw.js が返す 504）では落とさない。
  ただし DEM5A が 404 だった鍵を端末に記録し（`demMiss5a`・30日・4000件）、通信の失敗のときに記録があれば DEM10B で描く
  （sw.js は 404 を覚えないので、記録が無いと圏外で 10B に落ちられない）。**圏内ではいつも DEM5A を取りに行く**
- DEM10B は z14 まで。z15 で 10B なら z14 の親を計算し、4分の1を引き伸ばす（親の結果は4枚の子で共有）
- 出典は既存の「地理院タイル（標高タイル）を加工して作成」（出典欄が常に1回出す）

## 理由 / 検討した代案

- **却下: DEM10B だけ** … 全国で揃うが、5m の航空レーザーがある山でも粗くなる。微地形を読む目的に合わない
- **却下: 1枚の計算の中で DEM5A と DEM10B を混ぜる** … 源の境目に偽の尾根・谷が出る（ならしと曲率が段差を拾う）
- **却下: 通信の失敗でも DEM10B に落とす** … 圏外では DEM10B も控えに無ければ同じく失敗し、圏内の一時的な失敗で
  画面の一部だけ粗くなる。配信なしの記録で、圏外の必要な場面だけ救う
- **却下: 404 の記録を圏内でも使う（DEM5A を取りに行かない）** … 地理院が DEM5A の範囲を広げても粗いまま残る
- **保留: 前もっての一括取得** … 地理院の回答待ち（#229）。いまは見た範囲だけ（sw.js のタイル控え）
- **保留: サーバー（Actions）で画像を作って配る** … まず端末で実機の速さを測る。重ければ切り替える

## 影響

- `ciFetchBlob(z,x,y)`・`ciTileKey(z,x,y)` など CIマップの名前と戻り値は変えていない（`smoke_cimap` が見ている）。
  源の鍵は `ciTileKey` の4つ目の引数（栃木は従来どおり `z/x/y`）。取得・Worker・メインの復号のキャッシュはこの鍵で分かれる
- Worker に渡す関数は `CI_WORKER_FNS` に足す（`decodeGsiDem`・`csMargin`・`computeCsTile`）。外の定数を見ないこと
- 海に面した所・DEM5A の無い所は 10m で描かれる
- 標高タイルは地図タイルと同じ保存の上限（150MB・LRU）を使い、ほかの地図タイルを押し出すことがある
- 行の下の計測（取得・復号・計算の中央値）は試作の間だけ。実機で測り終えたら消す
