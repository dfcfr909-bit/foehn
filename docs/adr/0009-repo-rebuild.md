# ADR-0009: リポジトリを作り直して履歴から対象外の資料を除く（SotoKi → foehn）

- ステータス: 採用
- 日付: 2026-08-13
- 関連: ADR-0007（資料の分離）、ADR-0003（GitHub Pages）、ADR-0008（Netlify撤去）

## 背景

ADR-0007 で、気象アプリと無関係な業務由来の資料を別リポジトリへ分離した。
ただし**作業ツリーから消しただけ**で、過去コミットには残したままにしてある。
ADR-0007 はそこで「**履歴の書き換えは行っていない**（public リポジトリの全SHAが
変わり、影響が大きいため）。今後この判断を覆すなら新しいADRを書くこと」と記録した。

その後、**書き換えでは足りない**ことが分かった。

GitHub は Pull Request ごとに `refs/pull/*` という ref を自動で作る。
これは**リポジトリ側から削除も書き換えもできない**。`git push --force` が届くのは
`refs/heads/*` だけで、`refs/pull/*` は元のコミットを指したまま残り、
Pull Request の "Files changed" からそのまま読める。

調査したところ、**60本の PR のうち19本**に該当ファイルが載っていた。
つまり履歴を書き換えて force push しても、**19本の PR ページからは消えない**。

## 決定

**リポジトリを作り直す。**

`git-filter-repo` で該当パスを全履歴から除き、業務由来の語を含むコミットメッセージを
中立な文面へ書き換えたうえで、**新しいリポジトリ `foehn` に `main` だけを push する**。
旧 `SotoKi` は削除する。

これにより ADR-0007 の「履歴の書き換えは行っていない」は**覆る**
（ADR-0007 は不変。ここで更新する）。

## 理由 / 検討した代案

- **なぜ作り直すか**
  - `refs/pull/*` を消す手段がリポジトリ側に無い以上、同じリポジトリに手を入れても
    公開面は残る。新しいリポジトリには PR の履歴がそもそも無いので、**その面が最初から存在しない**
  - 作業ツリーの内容は変えずに済む（`main` のツリーハッシュが旧 `main` と一致することを
    移行時に検証した）。アプリの挙動は移行で変わらない

- **却下: force push だけで済ませる**
  - **目的を達成しない。** `refs/heads/*` は書き換わるが `refs/pull/*` は残るので、
    19本の PR ページに載ったままになる。「履歴を消した」と誤認して安心する分だけ悪い

- **却下: GitHub Support に `refs/pull/*` の purge を依頼する**
  - 依頼が通るかも、いつ通るかも**こちらで決められない**。公開状態が続く時間を
    自分で制御できないのは、この件の性質上あわない。作り直しなら即座に決着する

- **却下: リポジトリを private のままにして公開をあきらめる**
  - ADR-0003 のとおり公開先は GitHub Pages で、無料枠では private だと Pages が止まる。
    アプリを配信できなくなるので、問題の解決ではなく機能の放棄になる

- **古いブランチは持ち込まない。** `claude/*` 17本はすべてマージ済みか役目を終えている。
  持ち込めば消したはずのコミットを連れてくる経路になる

## 影響

- **全コミットの SHA が変わった。** 旧 SHA を指すリンク・メモ・手元のクローンは追えない。
  旧リポジトリを参照している作業ツリーがあれば捨てて取り直すこと
- **PR は復元していない。** `refs/pull/*` を持ち込まないことが目的なので、復元すると本末転倒
- **Issue は16件を作り直した。** 旧 `#54`〜`#73` → 新 `#1`〜`#16`（旧番号の昇順）。
  ドキュメント側の参照も置換済み。**旧 PR `#69` への言及だけは対応先が無いので残してある**
- **公開URLが変わった**（`.../SotoKi/` → `.../foehn/`）。
  旧URLで入れた PWA は別物として端末に残るので、**入れ直して古い方を消すこと**
- **タグは無い。** 旧リポジトリにもタグは打たれていなかったので、引き継いでいない
- ⚠ **`sotoki_v4.html` のファイル名は変えていない。** `sw.js` のキャッシュ、`index.html` の
  リダイレクト、`manifest.webmanifest`、テスト、`docs/spec/code_map.md` の関数索引が
  この名前に依存している（55箇所）。リネームは移行とは独立した変更なので、
  やるなら別PRで。移行と混ぜると切り分けができなくなる
- ⚠ **アプリ名「ナギナビ」/ `NAGI NAV` は変えていない。** 変えたのはリポジトリ名だけ
- **今後、公開したくないものを1コミットでも入れたら、同じ規模の作り直しが要る。**
  force push では消えない、というのがこの ADR の要点
