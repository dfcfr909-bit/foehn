# ADR-0012: 高度別の風の場は「升目の90パーセンタイル標高をならした高さ」の風を、気圧面の間の補間で作る

- ステータス: 採用（地表付近の埋め方だけ保留。下記「保留」）
- 日付: 2026-09-26
- 関連: ADR-0005（風速の単位）、ADR-0006（山頂高度の気圧面風）、ADR-0011（モデル地形を判定に使わない）、
  ADR-0010（格子点APIをブラウザから叩く形の限界）、PR #93（Phase 1a の調査）

## 背景

地図の風を Windy のように粒子で流したい。ただし目的は見た目ではなく、
**BCで人間が毎回やっている「気圧面を標高に読み替える作業」をシステムで行うこと**。
「この標高なら今日は850hPaくらい」「850が地中だから800を見る」という判断を
地点ごと・時刻ごとに自動で行い、**1枚の連続した風の場**（x, y, 時刻 → U, V）として描く。

そのためには「その場所の風」を何の高さで見るか（基準標高 z_ref）を決める必要がある。
Phase 1a の実測（`scripts/probeWindField.mjs` / `probeTerrainRef.mjs` / `probeWindSeam.mjs`）で
次のことが分かった。

| 事実 | 値（2026-09-26 実測） |
|---|---|
| 応答の `elevation`（既定） | **実際の地形**（山頂との差 中央 −32m） |
| 応答の `elevation`（`elevation=nan`） | **モデル地形**（山頂より 501〜2,204m 低い）。風の値は既定と100%同じ |
| モデル地形より下の気圧面 | **null ではなく外挿値が返る**（925hPa は峰の87%、850hPa は39%で地中） |
| 気圧面の間を高さで補間 | 層を1つ選ぶより誤差が約4〜5割小さい（800 を 850/700 から: 中央1.7 m/s、最寄り層 3.2） |
| 10m風 ÷ 最下の気圧面の風 | 0.1〜0.3。風向も16〜36°違う（摩擦を受けた別物） |
| 格子点1点の標高を z_ref にする | **モザイク**。隣の升目と区分（地表/上空）が入れ替わる割合 56% |

## 決定

1. **z_ref ＝ 升目（MSM 上空の格子 0.125°×0.1°）の中の地理院標高の90パーセンタイルを、隣の升目と 1-2-1 でならした値**（以下 p90s）。
2. **役割分担**: 実際の地形（p90s）で「どの高さの風を見せるか」を決め、
   **モデル地形（`elevation=nan`）で「その気圧面の値がモデル上で有効か」を決める**。
   モデル地形より下の面は外挿値なので候補から外す。
3. 気圧面の高さは**その時刻・その地点の `geopotential_height_{p}hPa` を使う**。固定表（850hPa≒1,460m 等）は使わない。
4. z_ref を上下から挟む有効な2面の U/V を**高さで線形補間**する。最近傍の層は選ばない。

## 理由 / 検討した代案

2つの山域（北アルプス〜松本盆地、越後〜尾瀬〜関東平野北縁。計160升目・72時間）で、
候補ごとに自動選択をかけ、隣の升目（約11km）との風の差と、区分の入れ替わりを測った
（`probeTerrainRef.mjs`、Actions #16）。

| z_ref の候補 | 隣との差 中央／90%（m/s） | 地表(10m)扱いの升目 | 隣と区分が違う | 判定 |
|---|---|---|---|---|
| 自然な場（参考）850hPa | 1.2 ／ 3.2 | – | – | – |
| 格子点1点 | 1.5 ／ 6.1 | 58% | **56%** | **却下**：谷か尾根かは点の位置の偶然。標本の取り方を描いてしまう |
| 平均 | 1.1 ／ 3.4 | 53% | **53%** | **却下**：モデル地形とほぼ同じ高さになり、区分が半々で入れ替わる |
| 中央値 | 1.1 ／ 3.3 | 68% | 42% | **却下**：同上。谷底の風を見せることになり BC の目的に合わない |
| 75% | 1.6 ／ 4.7 | 3% | 5% | 却下：まだ入れ替わりが残る |
| 最大 | 1.7 ／ 5.0 | 0% | 0% | 却下：画素1つ（山頂の先端）に左右される。タイルの解像度で値が変わる |
| 75% をならす | 1.4 ／ 3.5 | 6% | 11% | 却下：入れ替わりが残る |
| **90% をならす（採用）** | **1.4 ／ 3.4** | **0%** | **0%** | 自然な場と同程度に滑らか。**稜線と斜面上部＝BCで風にさらされる帯**を表す |
| 最大をならす | 1.4 ／ 3.4 | 0% | 0% | 次点。滑らかさは同じだが、表すのは山頂の先端だけで、滑走する斜面より高い |

- **90パーセンタイルを選ぶ理由**: 升目の中で「上から1割の地形」＝稜線と斜面の上部。
  BCで風が問題になるのは、ここ（風成雪・雪庇・稜線の通過）。最大値は面積のない1点で、
  滑走する斜面の代表にならない。平均・中央値は谷の側に寄り、モデル地形と重なって
  地表/上空の判定が半々に割れる（モザイクの原因そのもの）。
- **ならす理由**: 升目の境で稜線が切れると、隣とだけ高さが跳ぶ。1-2-1 の重みで隣と混ぜる。
  90% のままでも区分の入れ替わりは 0% だったが、隣との差の90%点が 4.7 → 3.4 m/s に下がった。
- **モデル地形で有効性を見る理由**: モデル地形より下の値は外挿で、null にならず普通の値に見える。
  実際の地形で判定すると、モデル上では空中にある有効な値まで捨てる（850hPa は峰の96%で山頂より下だが、
  モデル上の地中は39%）。逆にモデル上の地中の値を使うと、存在しない風を描く。
- **ADR-0011 との関係**: 0011 は「モデル標高で判定の層を決めない」とした。当時は応答の `elevation` が
  モデル地形だと思い込んでいたが、実際は**既定で実際の地形に補正されていた**。
  モデル地形は `elevation=nan` で今も取れる。本ADRはモデル地形を**層の有効性の判定だけ**に使い、
  見せる高さは実際の地形で決めるので、0011 の判断とは矛盾しない。

## 影響

- **地形表が要る。** 升目ごとの p90s を事前に計算した静的ファイル（地理院の標高から Actions で作る）。
  地理院の標高タイルはアプリで既に使っている情報源。公開物が増えるので、作る前に確認する
- **固定表で気圧面の高さを決めてはいけない。** `WIND_LEVELS` の高さ（ABC判定用）を風の場に流用しない
- **格子点1点の標高・平均・中央値を z_ref にしてはいけない**（モザイクになる。上の表）
- 気圧面の候補は定義の表で持つ（10m / 925 / 900 / 850 / 800 / 700）。
  900・800 は **MSM の期間にしか無い**（GSM に無い）。無い時刻に別の層で埋めない
- MSM → GSM の継ぎ目（`probeWindSeam.mjs`、Actions #15、2026-09-26 16:51 JST 実行）:
  - 800/900hPa は MSM 上空の最後の時刻（9/29 17時）まであり、その次から null。
    **seamless の null と msm の null は 1,536 件すべて一致**（代用値は入らない）
  - 925/850/700 は、その3時間前（15〜17時）から **MSM と GSM の混合値**（どちらとも一致しない）、18時から GSM
  - 10m は、さらに2時間前（13〜15時）から混合、16時から GSM
  - GSM の期間も値は1時間ごとに動く（6時間の値を Open-Meteo が補間している）
  - **seamless の `elevation=nan` は MSM のモデル地形**を返す。GSM のモデル地形はもっと低い
    （谷川岳 MSM 1,177m / GSM 925m、火打山 1,492m / 615m）。GSM の期間に MSM の地形で
    有効性を見ると安全側（使える面を少なめに見る）になる
  - 継ぎ目の1時間の風の変化は、ふだんの毎時の変化の 0.1〜3倍（850hPa）。新潟の10m風だけ7倍

## 保留

**地表付近（モデル地形と、有効な最下の気圧面の間）の埋め方。** 90% をならした場合、升目×時刻の35%がここに入る。
925hPa を伏せて「10m風と850hPa」から当てた答え合わせ（3,214件）:

| 埋め方 | 誤差 中央／90%（m/s） |
|---|---|
| 高さで線形に按分 | **2.1 ／ 4.7** |
| 10m風をそのまま | 2.5 ／ 6.0 |
| 高さの対数で按分 | 2.9 ／ 5.6 |
| 上の面をそのまま | 3.8 ／ 6.8 |

線形が最も近かったが、10m風と気圧面を線形でつなぐことは物理的に正しい形ではない（境界層）。
どれを採るかは利用者の判断を待つ。決まったら `docs/decisions.md` に1行で残す。
