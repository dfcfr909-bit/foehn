# ADR-0020: 1m の標高（DEM1A）は、CS立体図風の z16〜17 だけで使う。山域の保存は別の控えに置く

- ステータス: 採用
- 日付: 2026-10-17

## 背景

CS立体図風（ADR-0018）は DEM5A（5m）／DEM10B（10m）から z12〜15 で計算し、z16 以上は z15 を引き伸ばしている。
利用者の方針は「一番細かく見られる地図が描け、かつ実用に耐えること」「よく行く山域は細かい地形図をとっておきたい」（2026-10-17）。
地理院は DEM1A（1m・z1〜17・符号化は DEM5A と同じ）も配信しているが、**配信の欠けが多い**（那須・日光は山頂付近 100%、谷川は 3割ほど、火打は無し）。
配信ありのタイルにも画素の欠けがある（槍ヶ岳の山頂の z17 は画素の 12% だけ値あり）。範囲と大きさの実測は `docs/requirements_dem1m.md`。
尾根・沢の判定に効くのは 30m→10m の一段まで（`docs/decisions.md` 2026-09-29）。

## 決定

- **DEM1A は CS立体図風の z16〜17 だけで使う。** z12〜15 はいまのまま（DEM5A → DEM10B）。風の当たり方・CIマップ・判定・風の補正には使わない
- z16〜17 の1枚は、**同じズームの DEM1A の9枚（中心＋周り8）がすべてあり、計算に使う範囲に画素の欠けが1つも無いときだけ** 1m で計算する。
  それ以外（1枚でも 403・404・通信の失敗・画素の欠け）は **z15 の結果を切り出して引き伸ばす**（いまと同じ見え方）。1枚の中で源を混ぜない
- DEM1A が 404 だった鍵は `demMiss1a`（30日・4000件）に記録し、**記録のある9枚は圏内でも取りに行かない**（30日で記録が切れたら取り直す）
- ならしは 1m 用に別に持つ（`CS_PRM_1M`・σ=2m は仮。実機で決める）
- **山域の保存（段2）は、タイルの控え（LRU）とは別の箱**（`sw.js`）に置く。LRU より先に引き、`CACHE_VERSION` の更新でも消さない。
  取得は間隔を空けて控えめに（毎秒4枚・同時に1山域・1山域 1,100 枚まで）。一括の事前取得は地理院に問い合わせ中（#229）で、禁じられたら止める

## 理由 / 検討した代案

- **却下: 1枚の中で DEM1A と DEM5A を混ぜる・欠けを 5A で埋める** … 源の境目・欠けの縁に偽の崖や尾根が出る（ADR-0018 と同じ理由）
- **却下: 画素の欠けは透明にして 1m で描く** … 欠けの周りで曲率が段差を拾い、縁に偽の崖が出る。透明の穴も「地形が無い」と読み違える
- **却下: DEM5A と同じく、圏内ではいつも DEM1A を取りに行く** … 1A は落ちても z15 の引き伸ばし（いまと同じ見え方）で済み、地理院が範囲を広げても 30日で拾い直せる。
  毎回取りに行くと、欠けの多い山域（谷川・火打）で要求が無駄に増え（#229 の問い合わせ中でもある）、圏外の弱電波では応答を待ってしまう。
  ⚠ ADR-0018 は 5A について同じ方式（記録があれば圏内でも取りに行かない）を「範囲が広がっても粗いまま残る」として却下している。
  5A では記録が切れるまで z12〜15 全体が 10m に落ちるが、1A では落ちた先が今までと同じ表示で、損は「1m になるのが最長30日遅れる」だけなので、ここでは採る。ADR-0018 の 5A の決定は変えない
- **却下: 通信の失敗では描かない（失敗にする）** … z15 は控えにあることが多く、圏外で引き伸ばしでも出る方が役に立つ。z15 も無ければいまと同じく失敗
- **却下: z18 まで計算する** … DEM1A の配信は z17 まで。z18 は z17 の引き伸ばしで足りる
- **却下: 判定・風の当たり方にも 1m を使う** … 判定に効くのは 10m まで。風の当たり方は風上を最大 300m 見るので、1m では1枚の余白が膨らみ重い
- **却下: 山域の保存を LRU の控えに入れる** … 見た範囲の地図タイルに押し出され、圏外で必要なときに消えている

## 影響

- `csRenderTile` は z16〜17 で `csRender1m` を通る。z15 の結果は子で共有する（`csZ15`）。z15 以下の動きは変えない
- `computeCsTile` は prm の `whole` で「欠けがあれば null」になる。Worker・メインとも null を `empty` として返す
- 1A の要求は z16〜17 で CS立体図風を見たときだけ増える（1枚約 80〜90KB）。同じ LRU（150MB）を使い、ほかの地図タイルを押し出すことがある
- 1A のタイルと z15 の引き伸ばしのタイルが隣り合う所（配信の縁・欠けの周り）は、細かさの違う境目が見える。段3 の実機で見る
- σ=2m・cs0=0.01/m（5m と同じ満色）は**未確認**。1m では曲率が大きく出るので色が飽和しやすい見込み。段3 の実機で決める
- 1A の符号化が DEM5A と同じことは、男体山の z17 の実タイル1枚を復号して確かめた（欠け 0・標高 2,365〜2,483m・2026-10-17）
- 段2 では `sw.js` に新しい箱が増える（確認が要る区分）
