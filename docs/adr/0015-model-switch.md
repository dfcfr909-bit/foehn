# ADR-0015: 予報モデルを切り替えられるようにする（段階B）

- ステータス: 採用（要件。実装は未着手）
- 日付: 2026-09-30

## 背景

予報は Open-Meteo の `jma_seamless` 固定だった。段階A（v4.142.0）で、いまどのモデルか（MSM／移行／GSM）を帯と窓に出した。
利用者の要望は「基本は今のまま。ただし不確実性が高いときは、モデルを切り替えて見たくなることがある」。
要件の全文と各モデルの実測は `docs/requirements_model_switch.md`。

## 決定

1. **予報モデルを切り替えられるようにする。** 選べるのは **JMA（`jma_seamless`・既定）／GFS／ICON／ECMWF（`ecmwf_ifs025`）**。
2. **ABC 判定も、切り替えたモデルの値で出す。** 表示と判定は必ず同じモデル。モデル名は帯と窓に常時出す。
3. **切り替えは段階Aの帯をタップして行う。** **起動のたびに JMA へ戻す**（端末に覚えない）。
4. **地図の風（矢印・粒子）は連動しない。** JMA 固定で、地図に「JMA」と明記する。
5. **同時の重ね描き・平均・アンサンブルは、この段階では持たない。**
6. **出す前に、アメダス等の実測と比べて過小・過大を測る**（山頂の風の精度の検証）。

## 理由 / 検討した代案

- **表示と判定を同じモデルにする**：ずれると「予報通り」にならない。判定だけ JMA に固定する案は、表示と判定の食い違いを生むので却下。
- **選べるモデルを絞る**：
  - `ecmwf_ifs`（9km）は**気圧面の風を返さない**。山頂の風を作れず、黙って地上10m風に落ちる（ADR-0006/0011 の失敗の再来）→ 却下。
  - `ecmwf_aifs025` は**地上の列が全部空** → 却下。
  - `gem_seamless`（約10日）・`meteofrance_seamless`（約4日）は**予報が短く**、「データなし」が増える → 当面は外す。
- **起動で JMA に戻す**：「時々見たくなる」用途に合わせる。別モデルの判定を、気づかず使い続けるのを防ぐ。覚える案は却下。
- **地図を連動させない**：地図の風は別系統（`fetchWindColumns`・場の解析・地形補正）で、変更が大きい。まずチャートだけ。連動は別の要件で。
- **重ね描きを持たない**：切り替えで足りるかを先に見る。不確実性の可視化（モデル間のばらつき）は将来の別要件。
- **精度の検証を先に**：粗いモデルは山岳の風が過小に出やすい。JMA GSM 相当の層だけで按分した検証（2026-09-30）で、強風時に山頂の風が平均 1.3〜1.4m/s 過小に出た。
  ECMWF（層が疎）でも同じことが起きうる。切り替えて「予報通り」に近づく保証は無いので、測ってから出す。

## 影響

- **ABC 評価の関数（`abcScore` / `abcScoreInv` / `judgePoint`）は変えない。** 変わるのは入力の風・気温・降水などだけ。閾値は `THRESH` だけ。
- **山頂の風はモデルごとの気圧面の構成に合わせて gh 按分で作る。** JMA 専用の固定表（`WIND_LEVELS`）に寄りかかる設計から外す。
  気圧面が使えないモデルは候補に入れない（地上10m風に黙って落とさない）。
- **オフライン控えをモデルごとに分ける。** 別のモデルの控えを出さない。
- **予報が短いモデルは、足りない先を「データなし」にする。** 他のモデルで埋めない。
- 突風は、モデルが返すならそのモデルの値。返さない（JMA・IFS）なら現行どおり補助リクエスト（`best_match`）で、出どころを画面で分かるようにする。
- `windModelPhases`（MSM／移行／GSM の判別）は **JMA 専用**のまま。他モデルには当てはめない。
- `about.html` に、選べるモデルと妥協点を書く。
