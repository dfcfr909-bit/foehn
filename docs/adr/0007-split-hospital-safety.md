# ADR-0007: 院内安全資料（KYT・手術室インフォグラフィック）を別リポジトリへ分離する

- ステータス: 採用
- 日付: 2026-08-11

## 背景

このリポジトリには、気象アプリとは無関係な院内向け資料が同居していた。

- `kyt_form.html` — インシデントレポートKYT分析用紙（＋ `docs/kyt_*.md` / `worker/`）
- `or_safety_infographic.html` — 手術室 安全確認インフォグラフィック（＋ `illustrations/`）

CLAUDE.md・`docs/spec/code_map.md`・README のそれぞれに「**気象アプリとは独立した別物**」と
注記を書き足さないと事故る状態になっており、`docs/project_structure_proposal.md` でも
「将来的には別リポジトリが望ましい」と既に指摘されていた。

同居のまま放置すると、注記では防げない実害が3つあった。

1. **Service Worker が院内資料を巻き込む。** `sw.js` は同一オリジンのGETを全て
   キャッシュ対象にする（`isAppAsset` はオリジンしか見ない）。掲示物とイラストが
   気象アプリのキャッシュに入るうえ、HTMLのオフライン時フォールバックが
   `sotoki_v4.html` 固定なので、**オフラインで未キャッシュの掲示物を開くと
   天気アプリが表示される**。院内Wi-Fiが不安定な場所でスマホから開けば普通に起きる
2. **公開範囲。** ADR-0003 のとおり公開先は GitHub Pages（public前提）で、
   https://dfcfr909-bit.github.io/foehn/ 配下に置いたものは誰でも見られる。
   院内向けの様式と事例が公開URLに出ていた
3. **リポジトリの重量。** 分離時点で packed 231KB。イラスト12枚を入れると
   10〜20MBになり得る。気象アプリを触るたびに医療画像を引きずることになる

## 決定

院内安全資料一式を **private の別リポジトリ `hospital-safety`** へ、履歴ごと移した。
このリポジトリからは該当ファイルとテストを削除し、気象アプリ専用に戻す。

## 理由 / 検討した代案

- **なぜ別リポジトリか**
  - 上記3点はいずれも「同一リポジトリ・同一オリジンであること」から出ている。
    注記やディレクトリ分けでは消えず、分離でしか解けない
  - 資料は気象アプリとリリースサイクルも読者も共有しない。同じ `main` に乗せる必然性がない

- **なぜ private か**
  - 院内向けの様式・事例であり、公開URLに置く必然性がない。
    掲示・配布が目的なので、HTMLファイルの直接受け渡しか印刷で足りる
  - private だと GitHub Pages（無料枠）が使えないが、上記のとおり必要ない

- **却下: `docs/kyt/` などディレクトリで隔離する**
  （`docs/project_structure_proposal.md` の段階案）
  - ドキュメントの見通しは良くなるが、SWの巻き込みも公開範囲もリポジトリ重量も
    一切解決しない。実害が残る

- **却下: foehn 側の `sw.js` に除外パスを足して同居を続ける**
  - 1つ目の実害しか消えない。しかも「気象アプリのSWが医療資料を知っている」という
    逆方向の結合が増え、資料を追加するたびにSWを直す運用になる

- **却下: 資料ごとに1リポジトリずつ作る**
  - KYT と手術室資料は読者も配布経路も同じ（院内スタッフ向けの掲示・配布物）。
    テスト基盤も共有できる。分ける理由がない

## 影響

- **院内資料をこのリポジトリに戻さないこと。** 新しい掲示物や様式は `hospital-safety` 側に置く
- `worker/`（Cloudflare Worker）はこのリポジトリから消えた。
  ADR-0003 の「サーバ側の処理が必要になったら `worker/` に置く」は、
  **このリポジトリでは選択肢ではなくなった**。気象アプリで動的処理が要るときは
  置き場所から検討し直すこと
- テストは19件から16件になった（`smoke_kyt` / `smoke_worker` /
  `smoke_or_infographic` が `hospital-safety` へ移動）
- 分離前の履歴は `hospital-safety` 側に引き継いである。
  このリポジトリの過去コミットにも資料は残るが、**そちらを参照・復活させないこと**
- **過去コミットに残る院内資料は public のままである。** 分離後に調べたところ、
  `docs/kyt_form.md` に様式の出典として実在の施設名が書かれており、公開されていた。
  施設名は一般化したが、**履歴の書き換えは行っていない**（public リポジトリの全SHAが
  変わり、影響が大きいため）。個人を特定する情報・秘密情報は含まれていないことを
  確認済み。今後この判断を覆すなら新しいADRを書くこと
