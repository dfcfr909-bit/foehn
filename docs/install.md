# インストール（デスクトップアプリのように使う）

ナギナビは PWA なので、ブラウザから「インストール」するとデスクトップやホーム画面に
アイコンが並び、アドレスバーの無い独立したウィンドウで起動する。別途アプリを
配布する必要はない。

**インストール先URL**: https://dfcfr909-bit.github.io/foehn/

> ⚠️ `file://` で直接開いた場合と `http://` ではインストールできない（PWAはHTTPSが必須）。
> 上のURL（GitHub Pages）から開くこと。

## Windows / macOS（Chrome・Edge）

1. 上のURLを開く
2. アドレスバー右端の**インストールアイコン**（⊕ または画面付きのアイコン）をクリック
   - 見当たらないときは 右上の「⋮」→ **キャストして保存、共有** →「ページをアプリとしてインストール」
     （Edgeは「⋯」→「アプリ」→「このサイトをアプリとしてインストール」）
3. 「インストール」を押す

デスクトップとスタートメニュー（macOSはアプリケーションフォルダ / Launchpad）に
NAGI NAV が追加される。以降はそこから独立ウィンドウで起動する。

**タスクバー／Dockに固定する**: 起動中のアイコンを右クリック →「タスクバーにピン留め」
（macOSは Dock のアイコンを右クリック →「オプション」→「Dockに追加」）。

## macOS（Safari）

1. 上のURLを開く
2. メニューの **ファイル → Dockに追加**（Safari 17以降）
3. 名前を確認して「追加」

## iPhone / iPad（Safari）

1. 上のURLを Safari で開く（Chrome等ではホーム画面追加ができない）
2. 下部の**共有ボタン**（□に↑）をタップ
3. **「ホーム画面に追加」**をタップ → 「追加」

## Android（Chrome）

1. 上のURLを開く
2. 表示される「アプリをインストール」のバナー、または「⋮」→ **アプリをインストール**

## アンインストール

- Windows/macOS の Chrome・Edge: アプリを起動 →「⋮」→「NAGI NAV をアンインストール」
- iOS/Android: アイコンを長押しして削除

## 更新について

インストール後も、**起動のたびに最新版を取りに行く**（Service Worker がHTMLを
ネットワーク優先で扱っているため）。「更新したのに古い画面のまま」にはならない。

通信できないときはキャッシュから起動する。ただし気象データ自体は取得できないので、
最後に見ていた内容の表示にはならず、データ取得エラーになる。

## 仕組み（変更するとき用）

| ファイル | 役割 |
|---|---|
| `manifest.webmanifest` | アプリ名・アイコン・表示モード（`standalone`）・配色。インストールの可否はこれで決まる |
| `sw.js` | Service Worker。インストール要件を満たすためと、圏外での起動用。**HTMLはネットワーク優先** |
| `icons/icon.svg` | アイコンの原図（これだけ編集する） |
| `icons/*.png` | 書き出し済みアイコン。`node scripts/gen-icons.mjs` で再生成する |
| `scripts/gen-icons.mjs` | 原図から各サイズのPNGを書き出す。ImageMagick等が無い環境向けにChromiumで描画している |

アイコンを変えたら `icons/icon.svg` を編集して再生成し、生成物もコミットする
（GitHub Pages は静的配信なのでビルド工程が無い）。

本体を大きく変えたときは `sw.js` の `CACHE_VERSION` を上げる。古いキャッシュは
`activate` 時に削除される。
