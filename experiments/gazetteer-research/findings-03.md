## 1. 国土数値情報

一次情報: https://nlftp.mlit.go.jp/ksj/index.html （データ一覧。2026-10-07 取得）

- 一覧の「地形」は 標高・傾斜度メッシュ／低位地帯／大規模盛土造成地 だけで、**山岳（山名）のデータは無い**
- 山名を含みうるのは「観光資源（ポリゴン・ライン・ポイント）」（P12、2014年版）。
  一次情報: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P12-2014.html
  - 属性は 観光資源名・都道府県コード・行政区域コード・**種別名称**・所在地住所・観光資源分類コード。**読みの属性は無い**
  - 原典は（財）日本交通公社「観光資源台帳」の評価A級以上と、観光庁「観光地点等名簿」。**選ばれた観光地だけで網羅的ではない**
  - 使用許諾条件は**非商用**
  - 種別名称に「山岳」があるか、件数はいくつかは**未確認**（データ未取得）

## 2. 国土地理院の他のデータ

### 2-1. ベクトルタイルの注記（読みあり）

一次情報:
- 提供実験のページ https://maps.gsi.go.jp/development/vt_expt.html
  - 「提供するベクトルタイルは国土地理院コンテンツ利用規約に従って利用できます（実験的に提供するもので、基本測量成果ではありません）。」
  - 活用例2として「【地名情報】地名をクリックするとその地名の『よみ』を読み上げる地図」
- 地理院の公開リポジトリ `gsi-cyberjapan/gsimaps-vector-experiment`（`git clone` で取得、最新コミット 2026-09-18）
  - `data/lang-ja.js` に `"annoCtg" : "注記種別コード"`, `"knj" : "漢字"`, `"kana" : "読み"`
  - 使っているタイル: `https://cyberjapandata.gsi.go.jp/xyz/experimental_bvmap/{z}/{x}/{y}.pbf`

実測（2026-10-07、z=14 のタイル 274枚を復号。→ `raw/gsi_vt_labels_311_312.tsv`）

|---|---|---|---|
| 那須 | 1（那須岳） | 37 | 0 |
| 高原山 | 1（高原山） | 16 | 0 |
| 八甲田 | 1（八甲田山） | 24 | 0 |
| 尾瀬・燧 | 1（燧ヶ岳） | 15 | 0 |
| 光岳周辺 | 0 | 16 | 0 |
| **計** | **4** | **108** | **0** |

- 読みの例: 光岳＝てかりだけ、俎嵓＝まないたぐら、柴安嵓＝しばやすぐら、大鹿沼山＝おがぬまやま、鬼が面山＝おにがずらやま
- ⚠ 312 には山頂でないものも入る（熊見曽根・中の大倉尾根・牛ヶ首・雲谷峠）。**312＝山頂、ではない**
- ⚠ **注記の点は文字を置く位置で、山頂の座標ではない。**
  那須岳（311）と茶臼岳（312）は別の点に置かれていた（→ `raw/gsi_vt_attr_compare_nasu_z15.txt`）。
  標高は注記に無く、同じタイルの `elevation`（標高点）・`symbol`（三角点等、`alti` つき）との突き合わせが要る（**未検証**）
- ⚠ 種別コード 311・312・810 の**正式な定義表は見つけていない。**「311＝総称、312＝個々の山」は実データの傾向からの推定
- ⚠ 現行形式 `optimal_bvmap-v1` の注記（`Anno` レイヤー）は `vt_code`・`vt_text` だけで、**読みが無い**。
  旧形式 `experimental_bvmap` がいつまで配信されるかは**未確認**
- 注記の属性 `orgGILvl` は "25000"。告知（下記）が地名情報を「電子国土基本図（地名情報）」としているので、その 1/25,000 相当の地名と読める（`orgGILvl` の定義そのものは**未確認**）
- 地理院の告知「読めない地名も読み上げてくれます ～地名情報を機械判読可能なデータ形式でウェブ提供実験開始～」
  https://www.gsi.go.jp/johofukyu/johofukyu20170804.html （最終更新日 2017年8月4日）
  ⚠ この環境からは開けないため、**利用者が端末で開いた画面写真（2026-10-07）で本文を確認した**。読み取った内容:
  - 「国土地理院は、8月4日より、整備している地名情報のうち、居住地名、自然地名、公共施設、住居表示住所（※1）について、機械判読可能なデータ形式でのウェブ提供実験を開始しました。」
  - 「**居住地名と自然地名には、地名の『よみ』の情報も含まれています。**」
  - （※1）の参照先は「電子国土基本図（地名情報）」
  - 「今回提供を開始した地名情報は、**ベクトルタイル提供実験として公開**しています。データ提供の位置づけ、データ仕様等については、下記サイトに掲載しています。国土地理院ベクトルタイル提供実験サイト（GitHub）」
  - → 上の実測（`experimental_bvmap` の注記に `kana`）と合う。読みが入るのは**居住地名と自然地名**で、公共施設・住居表示住所には読みが無いと読める
  - リンク先の GitHub（データ仕様）は、この環境から Web 画面に到達できず**未確認**（注記種別コードの定義もそこにある可能性。**未検証**）

### 欠け方の傾向（実測からの所見）

- 百名山級でも欠ける（巻機山・笈ヶ岳・那須の茶臼岳）。**有名さで欠けが決まるわけではない**
- 総称（那須岳・燧ヶ岳・高原山）は `natural=volcano` の別の節点で入っている。山頂の peak と二重になる
