# 地名・山名検索の調査 05：国土地理院の住所検索API

対象: `https://msearch.gsi.go.jp/address-search/AddressSearch?q=<語>`
（本体の `gsiPlaceSearch()`、`sotoki_v4.html` の 12538行付近で使っている）

## 結論

- **API 単体の利用規約は見つからなかった。**
  - `https://msearch.gsi.go.jp/` と `/address-search/` は 403 で、説明のページが無い
  - 地理院地図の利用規約（https://maps.gsi.go.jp/help/termsofuse.html）の適用範囲は
    「『maps.gsi.go.jp』ドメインで公開しているウェブサイト」。**`msearch.gsi.go.jp` を名指ししていない**
  - 地理院地図の開発者向けページ（https://maps.gsi.go.jp/development/ichiran.html・siyou.html・vt.html）にも、この API の記載は見つからなかった
  - 地理院地図の「よくあるご質問」は GitHub の Issues（`gsi-cyberjapan/gsimaps`）にあるが、Web 画面と API に到達できず**未確認**
- **検索結果の保存・再配信の可否は未確認**（規約が見つからないため）
- 地理院地図 Vector も同じ API を使っている（`https://maps.gsi.go.jp/vector/js/src/util/addresssearcher.js` に
  `this._addressSearchUrl = 'https://msearch.gsi.go.jp/address-search/AddressSearch'`）

## 応答の実測（2026-10-07）

- 応答ヘッダー: `access-control-allow-origin: *`（ブラウザから直接呼べる）、CloudFront 経由
- 応答は GeoJSON 風の配列。1件は `geometry.coordinates`（[経度, 緯度]）と `properties` だけ
- `properties` の項目は **`title`・`addressCode`・`dataSource` の3つだけ**（今回の応答 173件の和集合）
  - **標高・種別・読みは無い**
  - `dataSource` は 1・3・4・5 と空の5通り。山名はおおむね 4、「字燧ケ岳」「釈迦ヶ岳開拓」などの字名は 5、
    トンネル・消防署などは 1 だった。**値の意味の公式な説明は見つからず未確認**
  - `addressCode` は市区町村コード（先頭0なし）と見られる（例: 9407＝那須町、7364＝檜枝岐村）。**未検証**
- **読み（ひらがな）で引ける**: 「ふじさん」→ 33件（富士山・小富士山・大藤山…）、「ひうちがたけ」→ 燧ヶ岳
- **表記ゆれの吸収**: 「笈ケ岳」でも「笈ヶ岳」が返る。「俎嵓」で「爼嵓」（みなかみ町）も返る
- 住所は「栃木県那須郡那須町」のように市区町村・大字の代表点が返る
- 件数の上限: 「富士山」で 82件返った（うち「富士山」そのものが 25件。上限は**未確認**）

## 代替の候補とライセンス

| 候補 | 中身 | ライセンス（一次情報） | 状態 |
|---|---|---|---|
| 国土数値情報「位置参照情報」 | 住所（街区・大字町丁目）と代表点の緯度経度 | 国土数値情報ダウンロードサイトの規約で **PDL1.0**（位置参照情報を含むと明記。出典記載例「出典：位置参照情報ダウンロードサービス（国土交通省）」）https://nlftp.mlit.go.jp/ksj/other/agreement.html | 規約は確認。データ本体は未取得 |
| アドレス・ベース・レジストリ（デジタル庁） | 住所の基礎データ | — | `www.registries.digital.go.jp`・`catalog.registries.digital.go.jp` に到達できず**未確認** |
| 地理院ベクトルタイルの注記 | 地名（住所ではない）＋読み | 国土地理院コンテンツ利用規約＝PDL1.0（→ `findings-04.md` 2.） | → `findings-03.md` |

⚠ 住所は山の天気アプリでは主役ではない（登山口の集落・駐車場の位置合わせ程度）。
オフラインで住所まで引けるようにするか、住所はオンライン時だけ API に任せるかは、データ量と規約の両面から人間の判断が要る（→ `findings-09.md`）。
