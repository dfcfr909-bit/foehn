# LANDMARK の予備実験（実験用・本番コードとは独立）

尾根・沢・鞍部の抽出を LANDMARK（Moretti & Orlandini 2023, JGR Earth Surface,
https://doi.org/10.1029/2022JF006943 ／ 実装 https://github.com/IGNF/landmark）に置き換えられるかを、
実際の DEM で確かめる予備実験。**`sotoki_v4.html` には一切手を入れない。**

## 進め方（利用者の指示・2026-09-30）

1. 小規模検証：男体山・常念乗越、10m 中心（30m と比較）
2. 明らかに有望なときだけ本格比較：飛騨乗越・5m・1m・精度の比較
3. 結論は A（有望→本格比較）／B（部分利用・ハイブリッド）／C（打ち切り）のどれか

確かめること：巨大斜面の誤検出が減るか／常念乗越の広く丸い稜線を拾えるか／主要な沢の階層（A_out・Horton 次数）／
Ridge・Thalweg・Saddle の接続と現行のコル（`terrainFindCols`）との整合／解像度依存性／処理時間

## ここまでに分かったこと（クラウドのセッション）

- **LANDMARK は pip で入り、動く**（`pip install -e .`。依存は numpy・shapely・tqdm・rasterio・geopandas、Python 3.10 以上）
- **処理時間**（偽の地形 `makeFakeDem.py`・Python 3.11）：200²升目（30m・6km四方）で 5秒、600²升目（10m・6km四方）で 64秒・最大メモリ約1GB。
  升目の数にほぼ比例（1升目1つの Python オブジェクト）。5m・6km四方（144万升目）は数分・数GB の見込み。**0.5m・1m は範囲を絞るか粗くする必要がある**
- **入力は投影座標（m）の GeoTIFF が必須**（緯度経度だと結果が壊れる）。平面直角座標系（栃木＝第IX系 EPSG:6677、長野＝第VIII系 EPSG:6676）でよい
- **閾値（a_out・a_spread・hso_th）は書き出しのときにしか使われない**（`junc_update` だけ例外で hso_th と a_out を見る）。
  全ネットワークを属性つきで取り出し、あとで A_out／A_spread で切る方が比べやすい（`model.dr_net` `model.rd_net` `model.rd_pt` `model.sdl_pt` を直接読む）
- ⚠ **LANDMARK の saddle は「窪地（内陸の流域）どうし・外へ抜ける流域をつなぐ溢れ口」**として作られる（`endo_del.py` の `find_saddle`）。
  範囲の外へ流れ出る流域どうしの境の最低点（＝山のコル）が saddle になるとは限らない。**現行の「峰どうしがつながる点」（prominence）と同じものかが最重要の確認点**。
  違うなら、稜線（rd_net）の上の極小点からコルを取り直す必要がある
- 尾根の点は升目の間（2倍の格子 `mat_id` の奇数の位置）に置かれる。尾根の線分の長さは升目の半分

## DEM の入手（利用者が手元で取得）

- ⚠ 地理院の 10m（DEM10B）は**等高線から作ったもの**でレーザーではない。現行の「約30m」は z12 のタイル（DEM10B を粗くしたもの）
- レーザー由来：基盤地図情報 DEM5A（5m）・DEM1A（1m）、県の森林レーザー 0.5m（G空間情報センター）
- **男体山**：栃木県「数値標高モデル(DEM)0.5m」の図郭 **`09HD1`**（平面直角 第IX系・山頂は x=−30.6km, y=+84.9km。周り±3km もこの1枚に入る）
  - 任意：`09FE3`（那須。鞍部の検証地点「峰の茶屋跡」「那須の丸地点」）
- **常念乗越**：長野県 森林情報オープンデータの 50cm DEM（第VIII系）。図郭はまだ割り出していない
- 基盤地図情報で取る場合の2次メッシュ：男体山 553903・553904・553913・553914、常念乗越 543735・543736・543745・543746
- **生データはリポジトリに入れない**（public・利用条件は未確認）。`experiments/landmark/data/` は置き場として `.gitignore` 済み
