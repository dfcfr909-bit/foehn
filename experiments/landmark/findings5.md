## 方法（共通）

**判定**：距離50m以内かつ標高差5m以内に saddle（または col）があれば「拾えた」（findings3・4 と同じ）。端・欠測境界から100m以内の基準点は除外（findings4 と同じ）。

**現行方式**：本番の `terrainFindCols` を、**実際の本番 JS を node で動かして**求めた。Python の再実装ではない。
- `runProdCols.mjs` が `sotoki_v4.html` から `COL` 定数・`terrainFindCols`・`terrainDemGrid` の「高い順の並び」（0.1m刻みの数え上げ）の**原文を文字列で抜き出して**実行する。本番コードは書き換えていない。
- 差し替えたのは `G.toLL`（地図が要るので座標は Python 側で復元）と `G.inner`（全域を採る）だけ。
- 入力の格子は、本番の「地理院 z12 タイルを平均した約30m」ではなく、**この実験の窓の DEM（30m・10m の GeoTIFF）をそのまま**使った。本番と完全に同じ格子ではない（30m の DEM は同じ z12 タイル由来だが、UTM への再投影で補間している）。
- 現行方式の手法は2つ：`PR_all`（落差3m以上＝本番が記録する床 `COL.FLOOR_M`）と `PR_d20`（20m以上＝既定の表示 `COL.SHOW_MIN_M`）。
- LANDMARK は `LM_all`（全 saddle）と `LM_d20`（落差20m以上）。

**偶然の値（ランダムな点）**：本物の基準点の代わりにランダムな点で同じ判定をする。乱数シード固定（20260930）。各窓・各解像度で2,000点。標高は DEM から取る。
- (a) 窓内の一様ランダム点。
- (b) 尾根状の点の上のランダム点。「尾根状」＝半径150mの両側がどちらも10m以上低い向きがある升目。窓内の20〜37%を占める（下に感度）。
  - ⚠ LANDMARK の尾根線は使わない。saddle は LANDMARK の尾根点の上に作られるので、それで偶然を測ると偶然の値が甘くなる。DEM だけから決めた簡易な定義で、どちらの手法にも依存しない。
- (b標高) (b) を、本物の基準点と標高を合わせて引いたもの（±20m、基準1点につき30点）。
- 表の「偶然」は、その帯（区分）の基準点の数に、ランダム点での一致率を掛けた**期待される一致数**（Recall換算も併記）。

- B1 の基準も同じ Union-Find 由来なので、**B1 は現行方式の評価には使えない**（同じアルゴリズムが自分の基準を拾うのは当然）。そのため作業2は B2 のみ。

### w07 の10mで saddle が桁違いに多い原因

**確認済みの事実**（位置図：`out/render/w07_10m_anomaly.png`。左＝陰影＋saddle、右＝平坦部）
- **saddle 4,780件の 75%（3,568件）は、窓内の 0.4% にしかならない平坦な升目**（5×5升目の起伏0.3m未満）の上にある。他の窓は 0〜60%（w08 53%・男体山 60%）。窓内の平坦部の割合そのものは、w07 が 0.4%、他窓が 0〜2.2% で大差ない。w07 の特徴は、狭い平坦面に saddle が密集する（平坦部1升目あたり約1.8件）こと。
- 平坦部は**谷底の2つの面**にまとまっている。約7.3ha（標高 288.9〜289.9m・saddle 1,632件が重なる）と約4.1ha（標高 309.8〜310.1m・754件）。面の中の標高幅は1m以内。左の面は窓の西端で切れていて、端の除外帯にも続く。
- 平坦部の上の saddle は 99% が「落差不明」（独立 Union-Find の col に対応づけられない）。
- 平坦部を除いた saddle は 1,212 件。他窓の 380〜710 件より多く、この分の原因は調べていない。
- DEM の欠測（窓内 0.4%）・投影の縁（平坦面は窓の内側）・標高の階段状の量子化（隣接同値率 0.46% は他窓の範囲 0.07〜0.73% の内側）は、主因ではない。

**推測**：2つの平坦面は、ダム湖など**水面**を DEM が一定の標高で埋めたものと考えられる（標高が1m以内で一定・谷底・10m単位に近い標高）。地形図・オルソ画像とは突き合わせていない。男体山の中禅寺湖岸で見た「渚の平坦部に saddle が並ぶ」現象（findings3 作業A）と同種と見ているが、確認していない。平坦面の上に saddle が並ぶ仕組み自体（mutual distance の判定が、標高差のほぼ無い面で候補を量産する）は、LANDMARK の中身までは追っていないので未確認。

**影響**：w07 の B1 の Recall（基準の col は平坦面の外）は、10–300m帯では窓全体と同程度（10–30m:67%・30–100m:92%）、5–10m帯は低め（30% 対 全体46%）。偶然の値は他の窓並み。findings4 の B1 集計に大きな歪みは見られないが、5–10m帯が低い理由は調べていない。saddle の総数や密度を指標にする場合は、平坦面（水面）を除く必要がある。他窓でも平坦部の上の saddle 率は w08 53%・w05 35%・w03 33%・nantai 60% と高く、同種と見られる。

## 結論（この追検証の範囲）

**確認済み**
- findings4 の B1・B2 の Recall は、偶然一致では説明できない（偶然は 5–10m 帯でも 1〜7%）。
- B2（OSM 基準点20点）では、LANDMARK と現行方式の Recall はほぼ同じ（差 0〜1点）。LANDMARK の候補数は現行方式の約2.5〜15倍で、偶然の値も高い。
- 端の除外幅（50〜200m）は結論を変えない。
- w07 の saddle の異常な多さは、谷底の2つの平坦面への集中で説明できる（面の正体は推測）。

**推測・未確認**
- 平坦面は水面か。
- 手法間で食い違った3〜4点のどちらが本物か。
- 5–30m帯の key col のうち、実在の鞍部がいくつか。
- 尾根状の定義（Δ=10m）以外での偶然の値（感度は見たが、定義の妥当性は主観）。

**結論を出さない**
- 「LANDMARK は現行方式より鞍部を拾える」とは言えない（B2 で差が出なかった。n=20）。
- 300m+ 帯（n=3）。
