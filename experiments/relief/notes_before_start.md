## 1. Issue #112（自作の地形レイヤーの覚え書き）から設計に反映すること

- σ（CS のならし）・R（CI の半径）は **m で決めて升目の数に直す**（升目の数で決めるとズームで見え方が変わる）
- **タイルごとに描く**（Leaflet の `GridLayer.createTile`）。σ・R はタイルの端をまたぐので、**周りのタイルも読んで余白を取る**
- **欠けたタイルは別の解像度で埋めない**（つなぎ目に偽の尾根・谷が出るおそれ）。欠けとして見せる
- `createImageBitmap` は `colorSpaceConversion: 'none'`・`premultiplyAlpha: 'none'` で読む（色の変換で標高が変わらないように）
- CI の符号は自分で決める：**＋＝発散＝尾根、−＝収束＝谷**（SAGA の説明の中で符号の書き方が食い違っている）
- 常念乗越のような頂が広く平らな稜線では、半径 60m の CI が低く出て稜線の大半を落とした（PR #111）。半径は地形の規模に合わせる必要がありそう
- CS の曲率は、円錐の斜面と丸い尾根がほぼ同じ値になる。見るための図としては問題ない（判定に使うのが問題）
- 見る用の層。`THRESH`・ABC 評価・風の補正には使わない
- 赤色立体図風（開度）は関連特許が未確認のため作らない。名前「赤色立体地図」はアジア航測のもの

## 2. 栃木県「数値標高モデル(DEM)0.5m」の利用規約・提供範囲・変換式

出典：G空間情報センター https://www.geospatial.jp/ckan/dataset/dem05_tochigi （組織：栃木県 森林整備課・ライセンス表示 CC-BY・メタデータ更新 2024-10-04）。利用規約 PDF「航空レーザ計測に基づく森林資源データの利用規約」（2023年8月1日制定）を読んだ。

### 利用規約（確認済みの事実）

- **第1 総則**：「どなたでも以下に従って、複製、公衆送信、翻訳・変形等の翻案等、自由に利用することができます。商用利用も可能です」
- **第2 出典の記載**
  - 利用するとき：「出典：栃木県森林資源データ（yyyy年計測）」または「栃木県森林資源データ（当該ページのURL）」など
  - 編集・加工して利用するとき：上の出典とは別に、編集・加工したことを書く（例「栃木県森林資源データ（yyyy年計測）を加工して作成」）。**あたかも栃木県が作成したかのような態様で公表・利用してはいけない**
- **第3**：日本法・宇都宮地方裁判所
- **第4 免責**：栃木県は利用者の行為・正確性等に責任を負わない。予告なく変更・移転・削除がありうる
- **第5 留意事項**：(1) 森林法第5条に基づき森林資源の現況把握のために作成したもので、同法に基づく事務以外に利用することを目的として作成したものではない（禁止ではなく注記の書き方）。(2) 令和3（2021）年以降に順次実施した航空レーザ計測の成果で、時期により精度が異なる
- **第6 その他**：(3) CC BY 4.0 と互換で、CC BY に従って利用することもできる
- データセットのページの説明：Terrain-RGB は「GIS等でタイルURLを接続することでご利用いただけます」

**判断**：ブラウザからタイルをリアルタイムに読んで CS立体図・CI を描く使い方は、**認められていると判断した**（第1の自由利用・翻案、CC BY 互換、タイルURLの接続を案内している）。
**推測・未確認**：タイルの直接の読み込み・アクセス量・キャッシュについての定めは無い。

**測量法の承認申請**：規約・データセットのページのどちらにも**記載は無い**。

### 提供範囲（図郭割の PDF）

- 県の西半分〜北部の山地が中心（図郭 09GD1〜GD4・GE1〜GE4・HD1〜HD4・HE1〜HE2 の一部・ID1〜ID4・JD2 の一部 など）。日光・那須・塩谷・鹿沼・佐野・足利など
- **宇都宮・真岡・益子などの東側の平地は範囲外**
- GeoTIFF は国土基本図の図郭単位（JGD2011／平面直角座標系）。データセットには 29 図郭の GeoTIFF がある（今回は使わない）

### Terrain-RGB タイルの形式（タイルを数枚メモリ上で読んで確認・保存していない）

URL：`https://rinya-tochigi.geospatial.jp/2023/rinya/tile/terrainRGB/{z}/{x}/{y}.png`

| 項目 | 値 |
|---|---|
| 形式 | XYZ タイル・ズーム 2〜18・EPSG:3857・256×256 の RGBA PNG |
| CORS | `Access-Control-Allow-Origin: *`（ブラウザから画素を読める）。`Cache-Control` は無し |
| 変換式（データセットのページ） | 標高＝−10,000＋(R×65,536＋G×256＋B)×0.1（**0.1m 単位**） |
| 変換式の確認 | 男体山の山頂付近で z15〜18 が 2,479.2〜2,480.9m。地理院 `dem5a_png` z15 の同じ点は 2,480.70m。式は合っている |
| 範囲外（県内・宇都宮） | HTTP 200・全画素が透明（A=0・RGB 0,0,0）の 334 バイトのタイル |
| 県外（群馬） | HTTP 403 |

ズームごとの画素の大きさ（北緯 36.77° 付近・地上距離）：

| ズーム | 12 | 14 | 15 | 16 | 17 | 18 |
|---|---|---|---|---|---|---|
| 画素 | 30.62m | 7.65m | 3.83m | 1.91m | 0.96m | 0.48m |

→ **欠けの扱い**：A=0 の画素と HTTP 403 のタイルは、どちらも欠けとして扱う。

参考：地理院の標高タイル（`dem_png` z14・`dem5a_png` z15 など）は x＝R·65,536＋G·256＋B を 0.01m 単位・2²³ が欠測（Issue #112）。`dem5a_png` も `Access-Control-Allow-Origin: *` を確認した。

## 3. 判断を求めている3点（利用者の返事待ち）

1. **栃木のタイルを使ってよいか**：規約上は認められていると判断した（上の 2）。この判断で栃木のタイルも使って進めてよいか。使わない場合は、依頼どおり地理院のタイルだけで進める
2. **出典の計測年の表記**：データセットのページには「令和3～4年度に栃木県が実施した航空レーザ測量」とあり、場所ごとの計測年は分からない。「栃木県森林資源データ（2021〜2022年度計測）を加工して作成」でよいか
3. **0.1m 単位の扱い**：栃木は 0.1m 単位で、地理院の 0.01m より粗い。z17・z18（約1m・0.5m）で曲率を取ると、0.1m の段差が細かい模様として出るおそれがある（推測）。このまま作って見え方で判断する、で進めてよいか
